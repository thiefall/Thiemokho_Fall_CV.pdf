## 🔬 Selected research

### 🧮 Symbolic Regression & Explainable Machine Learning
*AIMS Senegal — 2024–2026*
Using genetic programming (`gplearn`) to discover interpretable analytical relationships directly from data, balancing accuracy against expression complexity to recover physically meaningful models.

### ⛏️ MINERALS-AI Senegal — Scientific Coordinator
*MESRI / ESPOIR-Jeunes — 2026–2027*
Coordinating an interdisciplinary project combining AI, mathematical modeling and multi-source scientific data, with a focus on data fusion, spatial modeling, uncertainty analysis and a prototype decision-support system.

### 🌱 Spatio-temporal Modeling of Sahelian Vegetation Dynamics
*Centre de Suivi Écologique — 2025–2026*
Multi-decadal analysis (1984–2025) fusing Landsat NDVI, CHIRPS, ERA5-Land and TerraClimate, with ConvLSTM models and spatial clustering to link climate variables to vegetation dynamics.

### 🛰️ AI-based Data Science for Complex Scientific Systems
*PanAfrican Mineral Resources — 2025*
Python workflows integrating geological, geochemical, geophysical and satellite-derived data for anomaly detection and predictive modeling.

> 📄 **Publication:** *Multi-source Geoscientific Data Fusion, Deep Learning (FCN) and Spatially Constrained Clustering for Gold Potential Mapping in the Senegalese Basement (Mako Area)* — 5th International Conference on Modeling (CIM), UCAD. Second author and presenter.
